# Frontend Module — Owner: Balaganesh

## Responsibility
- React + Cesium.js interactive 3D globe dashboard
- Real-time satellite position rendering
- Conjunction event visualization (close approach indicators)
- Risk ranking panel with SHAP explanations
- Maneuver advisory display
- Alert system for high-risk events

## Key Components
- `Globe.jsx` — Cesium.js 3D globe with satellite entities
- `RiskPanel.jsx` — Ranked conjunction risk table
- `ConjunctionDetail.jsx` — Detailed event view with geometry
- `ManeuverView.jsx` — Delta-v advisory visualization
- `AlertBanner.jsx` — Real-time high-risk event alerts
- `SHAPChart.jsx` — SHAP waterfall/bar chart component

## Tech Stack
- React 18+
- Cesium.js (CesiumWidget)
- Vite (build tool)
- CSS Modules or vanilla CSS
